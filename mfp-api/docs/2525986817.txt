# Post Operation Log API
version 2 2026-03-26T18:46:13.115Z


Purpose
Use this API to submit ship operation metrics for a specific date.
You can:
submit metrics for one ship (
single
 endpoint), or
submit metrics for multiple ships in one request (
bulk
 endpoint).
Authentication
Include your API key in every request header:
mfp-apikey: <your-api-key>
Content-Type: application/json
Base Routes
Single ship
POST /API/v1/{grid_id}/{shipICESPlatformCode}/operationlog/post
Bulk
POST /API/v1/{grid_id}/operationlog/post_bulk
