Purpose

Use this endpoint to retrieve the list of available metrics that can be posted to the Operation Log API.

Typical use:

  • load metrics in your client

  • map metric IDs to metric names and value types

Authentication

Send the API key in request headers:

  • mfp-apikey: <your-api-key>

  • Content-Type: application/json

Endpoint

Method

URL

/API/v1/{grid_id}/metrics/read
