2. Download Files
Request
Description
Downloads one or more files associated with the specified equipment as a ZIP archive.
Path Parameters
Parameter 
Type 
Description 
grid.id  
string 
Your grid identifier 
id 
integer 
Equipment ID to download files for 
Query Parameters
Parameter 
Type 
Description 
file_ids 
integer[]
Array of file IDs to include in the download. If not specified, all files will be included. 
Response
A binary file stream containing a ZIP archive with the requested files.
The filename format will be: 
{Barcode}_{EquipmentName}_{CurrentDate}.zip
Special Features
The ZIP archive handles:
International characters in filenames
Duplicate filenames (by appending a counter)
Removal of invalid characters from filenames
