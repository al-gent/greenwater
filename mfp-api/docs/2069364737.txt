When 
equipmentCodeName
 and/or 
equipmentCodeValue
 are provided, the endpoint performs bottom-up filtering: it first finds matching Equipment Codes, then returns only Equipment that have those codes. All other filters are applied on top of this filtered set.
Filter Combination Rules
The endpoint supports 
full combinability
 of filters.
Examples:
Filter by Barcode + Active
Filter by Manufacturer + Description
Filter by Date Range + Location
Filter by Sensor + EventTrigger + Status
Each filter narrows the result set.
If a filter is omitted, it is simply ignored.
