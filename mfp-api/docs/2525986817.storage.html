Purpose

Use this API to submit ship operation metrics for a specific date.

You can:

  • submit metrics for one ship (single endpoint), or

  • submit metrics for multiple ships in one request (bulk endpoint).

Authentication

Include your API key in every request header:

  • mfp-apikey: <your-api-key>

  • Content-Type: application/json

Base Routes

Single ship

POST /API/v1/{grid_id}/{shipICESPlatformCode}/operationlog/post

Bulk

POST /API/v1/{grid_id}/operationlog/post_bulk

Error Responses

400 Bad Request

Returned when request data is invalid, for example:

  • missing required path parameters

  • missing body

  • invalid Date

  • empty Metrics

  • a metric without Id

  • ICESPlatformCode mismatch on single endpoint

404 Not Found

Returned when:

  • grid_id is unknown

  • shipICESPlatformCode is unknown (single endpoint)

500 Internal Server Error

Returned when data could not be saved.
