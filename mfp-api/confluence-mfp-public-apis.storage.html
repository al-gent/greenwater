1. Introduction

The MFP Public API Documentation provides a central hub for accessing and understanding the various APIs offered within the Maritime Framework Platform (MFP). These APIs enable seamless integration with cruise information, participant data, inventory management, and ship datasets.

This space is designed to help developers, data analysts, and project stakeholders quickly find the right API, understand its purpose, and access the related documentation. Each API page contains details about its endpoints, usage examples, and technical specifications.

Use this documentation to:

  • Discover which APIs are available and what data they provide.

  • Learn how to interact with each API effectively.

  • Ensure consistent and reliable integration across MFP systems.

Whether you are building new applications, automating workflows, or analyzing maritime data, this documentation will guide you in making the most of the MFP Public APIs.
